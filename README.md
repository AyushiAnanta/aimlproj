# Social Media Sentiment + Engagement Predictor

An end-to-end Machine Learning pipeline that predicts **sentiment** (Positive, Negative, Neutral) and estimates **engagement metrics** (likes) for social media posts.

---

## 📌 Project Overview & Architecture

1. **Sentiment Classification Pipeline**:
   - Uses pseudo-labeling with a transformer teacher (`cardiffnlp/twitter-roberta-base-sentiment-latest`) across ~2,000 tweets.
   - Trains standard scikit-learn student classifiers (`LogisticRegression`, `LinearSVC`, `SGDClassifier`) over blended word (1-2 n-gram) and character (3-5 n-gram) TF-IDF features.
   - Evaluates confidence-weighted training (`sample_weight` derived from teacher confidence) versus unweighted training.
   - Produces predictions via a majority-voting ensemble of the three models.

2. **Engagement Prediction**:
   - Predicts likes using `GradientBoostingRegressor` on log-transformed targets (\(\log(1 + \text{likes})\)).
   - Features audience reach (\(\log(\text{followers})\)), text length, word count, hashtag presence, media presence, and verification status.
   - Feature parity is enforced between training and single-instance inference through shared feature construction modules (`src/features.py`).

3. **Interactive Streamlit Interface**:
   - Single-text inference with sentiment voting breakdown and engagement estimations.
   - Transparently labels derived heuristic projections (e.g., retweets and replies) rather than misrepresenting them as independent ML models.
   - Bulk CSV processor computing engagement rates with division-by-zero protection.

## ⚙️ Setup & Installation

Clone the repository and install dependencies in your virtual environment:

```bash
git clone <repo-url>
cd aimlproj
pip install -r requirements.txt
```

---

## 🚀 Running Training and the Web App

### 1. Train Sentiment Models & Generate Reports
```bash
python -m src.train_sentiment
```
Outputs trained models to `models/` and generates evaluation artifacts (`results/metrics.json`, `results/cv_results.csv`, `results/confusion_matrix.png`, and `results/classification_report.txt`).

### 2. Train Engagement Models & Benchmark Baselines
```bash
python -m src.train_engagement
```
Computes baseline comparisons and outputs `results/engagement_comparison.csv`.

### 3. Run Tests
```bash
python -m pytest tests/test_pipeline.py -v
```

### 4. Launch Streamlit Application
```bash
streamlit run streamlit_app.py
```

*The metrics below are copied directly from generated outputs in `results/metrics.json` and `results/engagement_comparison.csv`.*

### Sentiment Classification Performance (Test Split, n=401)
*Metric measures agreement with RoBERTa pseudo-labels (not human ground truth).*

| Model / Configuration | Agreement with RoBERTa | Macro-F1 | Precision (Neg/Neu/Pos) | Recall (Neg/Neu/Pos) |
|---|---|---|---|---|
| **Majority-Class Baseline** | 0.4838 | 0.2174 | - | - |
| **Logistic Regression (Weighted)** | 0.6359 | 0.6268 | 0.60 / 0.68 / 0.59 | 0.61 / 0.65 / 0.62 |
| **LinearSVC (Weighted)** | 0.6309 | 0.6264 | 0.63 / 0.68 / 0.57 | 0.62 / 0.64 / 0.62 |
| **SGDClassifier (Weighted)** | 0.6185 | 0.6109 | 0.61 / 0.68 / 0.55 | 0.58 / 0.62 / 0.63 |
| **Majority-Vote Ensemble (Weighted)** | **0.6334** | **0.6294** | 0.64 / 0.68 / 0.57 | 0.62 / 0.64 / 0.62 |

#### Stratified 5-Fold Cross-Validation (Macro-F1)
- **Logistic Regression**: Weighted = \(0.6276 \pm 0.0095\) vs. Unweighted = \(0.6235 \pm 0.0126\)
- **LinearSVC**: Weighted = \(0.6174 \pm 0.0162\) vs. Unweighted = \(0.6033 \pm 0.0093\)
- **SGDClassifier**: Weighted = \(0.6013 \pm 0.0104\) vs. Unweighted = \(0.5946 \pm 0.0187\)

### Engagement Model Comparison (Test Split, n=199)

| Model Variant | Test R² (log) | Test MAE (log) | Test MAE (raw likes) | 5-Fold CV R² (mean) | 5-Fold CV R² (std) |
|---|---|---|---|---|---|
| **(a) Baseline: Median Likes** | -0.0006 | 1.4915 | 1183.3 | 0.0000 | 0.0000 |
| **(b) Follower Count Only** | 0.0850 | 1.3655 | 1141.2 | 0.1173 | 0.0189 |
| **(c) Metadata (Followers, Text Len, Media, Verified, Hashtags)** | 0.2250 | 1.2378 | 1095.7 | 0.2216 | 0.0173 |
| **(d) Full Model (Metadata + Sentiment Probs)** | 0.3118 | 1.1861 | 1088.7 | 0.2680 | 0.0275 |

**Baseline Outcome Summary:**
- Audience size alone (\(\log(\text{followers})\)) explains only ~8.5% to 11.7% of engagement variance.
- Adding non-sentiment metadata features (media, verified status, text length, hashtags) raises test \(R^2\) to 0.2250.
- When continuous sentiment probabilities from the RoBERTa model are incorporated, test \(R^2\) reaches 0.3118 (5-fold CV \(R^2 = 0.2680\)), showing incremental predictive utility.

## ⚠️ Limitations & Honesty Statement

1. **No Human-Labeled Ground Truth**:
   The sentiment target labels in `twitter_with_roberta_labels.csv` are pseudo-labels generated by `cardiffnlp/twitter-roberta-base-sentiment-latest`. No manual human annotation was performed. All reported metrics measure **agreement with RoBERTa labels**, not genuine classification accuracy.
2. **Dataset Size & Missing Upstream Data**:
   The engagement dataset comprises 993 filtered rows from `twitter-posts.csv`. The notebook references an upstream file `newtwitter.csv` which was not included in the repository; the origin of the 2,001 rows in `twitter_with_roberta_labels.csv` cannot be independently reproduced from scratch.
3. **Derived Metrics in UI**:
   Retweet and reply metrics in the Streamlit web application are not output by distinct machine learning models; they are heuristic multipliers of the estimated likes count.
